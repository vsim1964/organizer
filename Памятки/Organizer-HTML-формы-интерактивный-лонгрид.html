Формы: как браузер собирает данные

От простого текстового поля до полной формы задачи в Organizer. Посмотрите, как выглядит каждый элемент, измените его атрибуты, заполните форму и исследуйте результат отправки. Параллельно будем разбирать, что именно означает каждая строка HTML.

01 / Основная идея

Как работает форма

HTML-форма — область документа, которая объединяет поля ввода и задаёт способ отправки их значений. Пользователь вводит данные в браузере, браузер проверяет часть ограничений и собирает набор пар «имя — значение». Сам HTML не сохраняет задачу в базе данных.

1Поля HTML
2Ввод человека
3Проверка браузера
4Пары name=value
5Обработка программой

Что делает браузер

Отображает текстовые поля, списки, флажки и кнопки. По атрибутам required, type, min и другим выполняет часть проверок. При обычной отправке формирует HTTP-запрос.

Чего HTML не делает

Не регистрирует пользователя, не создаёт задачу в базе, не проверяет права доступа, не рассылает уведомления. Для этого позднее потребуются JavaScript и серверная часть приложения.

Полезная модель. Форма похожа на анкету: у каждого ответа есть название вопроса (name) и само значение. id — адрес элемента внутри страницы, а не имя поля в отправляемых данных.
HTML
<form action="/tasks" method="post">
  <label for="title">Название задачи</label>
  <input id="title" name="title" type="text" required>
  <button type="submit">Сохранить</button>
</form>

Адрес /tasks здесь условный: в нашем учебном прототипе сервер по нему не настроен. Ниже для практики мы будем перехватывать отправку в JavaScript, не посылая реальные запросы.

02 / Грамматика HTML

Элемент, тип, атрибут и значение

Прежде чем выбирать подходящее поле, полезно различать четыре уровня описания. Один и тот же элемент input может быть текстовым полем, датой или флажком: это определяется атрибутом type.

Элемент

<input> — отдельное поле. <textarea> — многострочный текст. <select> — список вариантов. <button> — кнопка. Они имеют разное назначение.

Атрибут

type="date" указывает разновидность поля. name="dueDate" называет данные при отправке. required делает поле обязательным при стандартной проверке.

Четыре строки — четыре разных задачи
HTML
<label for="taskPriority">Приоритет</label>
<select id="taskPriority" name="priority">
  <option value="low">Низкий</option>
  <option value="high">Высокий</option>
</select>

label называет поле для человека; for связывает подпись с id списка; name задаёт имя отправляемого параметра; value у option задаёт значение выбранного пункта. Если выбрана надпись «Высокий», отправится priority=high.

Логические атрибуты: required, disabled, checked, selected, multiple работают уже при наличии атрибута. Запись disabled="false" всё равно отключит поле: для снятия ограничения атрибут нужно убрать.
03 / Атлас

Как выглядят поля и как их записывают

Ниже собраны основные элементы и типы поля input, которые встречаются в веб-приложениях. Каждый пример — настоящий элемент браузера. Можно вводить данные, переключать варианты и раскрывать типичный HTML-код. Примеры не отправляют данные на сервер.

Текст

Однострочное текстовое поле

input · text

Поле подходит для коротких строк. При type="text" браузер не ограничивает смысл вводимых символов.

Полезные атрибуты: type, id, name, placeholder, required, minlength, maxlength, autocomplete
Показать HTML-код
HTML
<label for="title">Название задачи</label>
<input id="title" name="title" type="text" placeholder="Например, написать отчёт" required>

Поиск

Поисковая строка

input · search

Поле близко к text, но браузер может предложить специальную кнопку очистки. Сама фильтрация без JavaScript не появляется.

Полезные атрибуты: name, placeholder, autocomplete
Показать HTML-код
HTML
<label for="search">Поиск задач</label>
<input id="search" name="q" type="search" placeholder="Найти задачу">

Электронная почта

Адрес электронной почты

input · email

Браузер проверяет формат адреса, но не подтверждает существование почтового ящика.

Полезные атрибуты: required, autocomplete, multiple
Показать HTML-код
HTML
<label for="email">Почта</label>
<input id="email" name="email" type="email" autocomplete="email" required>

Пароль

Поле со скрытыми символами

input · password

Символы скрываются на экране, но это не шифрование. Для безопасной передачи требуется HTTPS, а пароль на сервере хранят в виде защищённого хеша.

Полезные атрибуты: minlength, maxlength, autocomplete, required
Показать HTML-код
HTML
<label for="password">Пароль</label>
<input id="password" name="password" type="password" minlength="8" autocomplete="new-password" required>

Телефон

Поле для телефонного номера

input · tel

Тип tel сам по себе не проверяет формат телефона; при необходимости используют pattern и серверную проверку.

Полезные атрибуты: autocomplete, pattern, placeholder
Показать HTML-код
HTML
<label for="phone">Телефон</label>
<input id="phone" name="phone" type="tel" autocomplete="tel" placeholder="+7 ...">

Ссылка

Веб-адрес

input · url

Браузер проверяет синтаксис URL при отправке; доступность адреса он не проверяет.

Полезные атрибуты: placeholder, required
Показать HTML-код
HTML
<label for="source">Ссылка</label>
<input id="source" name="source" type="url" placeholder="https://example.org">

Число

Числовое поле

input · number

min и max задают границы, step — допустимый шаг. Для номера телефона number не подходит: это не арифметическая величина.

Полезные атрибуты: min, max, step, required
Показать HTML-код
HTML
<label for="hours">Оценка, часы</label>
<input id="hours" name="hours" type="number" min="0" max="100" step="0.5">

Дата

Выбор календарной даты

input · date

В данных форма передаёт дату в формате ГГГГ-ММ-ДД. Вид календаря зависит от браузера.

Полезные атрибуты: min, max, required, value
Показать HTML-код
HTML
<label for="due">Срок выполнения</label>
<input id="due" name="dueDate" type="date" min="2026-01-01">

Время

Выбор времени

input · time

Обычно отправляется ЧЧ:ММ; step задаётся в секундах. 900 секунд — 15 минут.

Полезные атрибуты: min, max, step
Показать HTML-код
HTML
<label for="at">Время</label>
<input id="at" name="at" type="time" step="900">

Дата и время

Местные дата и время

input · datetime-local

Выбранное значение не содержит информацию о часовом поясе.

Полезные атрибуты: min, max, step
Показать HTML-код
HTML
<label for="meeting">Начало встречи</label>
<input id="meeting" name="meeting" type="datetime-local">

Месяц

Месяц и год

input · month

Значение обычно имеет вид ГГГГ-ММ. Внешний интерфейс зависит от браузера.

Полезные атрибуты: min, max, value
Показать HTML-код
HTML
<label for="period">Месяц</label>
<input id="period" name="period" type="month">

Неделя

Неделя года

input · week

Значение имеет вид 2026-W47. Поддержка графического выбора зависит от браузера.

Полезные атрибуты: min, max, value
Показать HTML-код
HTML
<label for="week">Неделя</label>
<input id="week" name="week" type="week">

Многострочный текст

Поле для длинных заметок

textarea

У textarea нет атрибута type. Исходный текст внутри открывающего и закрывающего тегов, а не в value.

Полезные атрибуты: rows, cols, minlength, maxlength, required, placeholder
Показать HTML-код
HTML
<label for="description">Описание задачи</label>
<textarea id="description" name="description" rows="4" placeholder="Подробности задачи"></textarea>

Выпадающий список

Один из заданных вариантов

select

Пользователь видит подписи вариантов. При выборе «Высокий» отправится priority=high.

Полезные атрибуты: name, id, required, multiple, size; у option — value, selected, disabled
Показать HTML-код
HTML
<label for="priority">Приоритет</label>
<select id="priority" name="priority" required>
  <option value="">Выберите приоритет</option>
  <option value="low">Низкий</option>
  <option value="medium">Средний</option>
  <option value="high">Высокий</option>
</select>

Флажок

Независимое условие «да/нет»

input · checkbox

Неотмеченный флажок обычно не добавляет свою пару в данные формы. Несколько checkbox могут иметь одинаковое name.

Полезные атрибуты: checked, value, name, required
Показать HTML-код
HTML
<label><input type="checkbox" name="important" value="yes"> Важная задача</label>

Переключатели

Один выбор из группы

input · radio
Доступ

Для взаимного исключения радиокнопок у них должен быть одинаковый name в пределах одной формы.

Полезные атрибуты: name (одинаковое в группе), value, checked, required
Показать HTML-код
HTML
<fieldset>
  <legend>Доступ</legend>
  <label><input type="radio" name="access" value="private" checked> Личная</label>
  <label><input type="radio" name="access" value="team"> Командная</label>
</fieldset>

Ползунок

Выбор числа на шкале

input · range

Удобен для приблизительных значений. Браузер сам по себе не обязан показывать выбранное число рядом.

Полезные атрибуты: min, max, step, value
Показать HTML-код
HTML
<label for="progress">Готовность</label>
<input id="progress" name="progress" type="range" min="0" max="100" step="5" value="35">

Выбор цвета

Палитра для выбора цвета

input · color

Передаёт выбранный цвет, как правило, в шестнадцатеричном формате #RRGGBB.

Полезные атрибуты: value, name
Показать HTML-код
HTML
<label for="color">Цвет проекта</label>
<input id="color" name="color" type="color" value="#247a78">

Загрузка файла

Выбор файла на устройстве

input · file

accept подсказывает допустимые типы, но не защищает сервер. Для файлов обычно используют multipart/form-data.

Полезные атрибуты: accept, multiple, name; у формы — enctype
Показать HTML-код
HTML
<label for="attachment">Вложение</label>
<input id="attachment" name="attachment" type="file" accept=".pdf,.png,.jpg" multiple>

Скрытое поле

Техническое значение в форме

input · hidden

Скрытое поле не видно на странице, но его легко посмотреть или изменить через инструменты браузера. Это не средство защиты.

Полезные атрибуты: name, value
Показать HTML-код
HTML
<input type="hidden" name="taskId" value="42">

Кнопки

Отправка, сброс, произвольное действие

button

submit запускает отправку, reset восстанавливает исходные значения, button не выполняет действия без обработчика.

Полезные атрибуты: type: submit, reset, button; disabled, form, name, value
Показать HTML-код
HTML
<button type="submit">Сохранить</button>
<button type="reset">Сбросить</button>
<button type="button">Открыть справку</button>

Группа связанных полей

Планирование

  <legend>Планирование</legend>

04 / Справочник

06 / Механизм отправки

От формы к HTTP-запросу

У стандартной формы есть action — адрес получателя, и method — способ отправки. В обычном GET параметры добавляются к URL; в POST они обычно находятся в теле запроса. Это не означает, что POST сам по себе шифрует данные: для защиты передачи необходим HTTPS.

GET — параметры в адресе

Подходит для поиска и фильтрации, когда результат можно открыть по ссылке. Не следует передавать таким способом пароли.

HTML
<form action="/tasks" method="get">
  <input name="q" type="search">
  <button type="submit">Искать</button>
</form>

POST — данные в теле

Часто используется при создании или изменении записей. Метод сам по себе не делает запрос безопасным и не гарантирует сохранение.

HTML
<form action="/tasks" method="post">
  <input name="title" type="text">
  <button type="submit">Создать</button>
</form>

Интерактивная отправка без сервера

Заполните поля и выберите GET или POST. Мы не делаем реального сетевого запроса: пример покажет, что браузер подготовил бы к отправке.

Как выглядел бы запрос
Заполните поля и нажмите «Показать отправку».
FormData: это браузерный объект JavaScript, который собирает доступные для отправки пары полей. Варианты с одинаковым name могут передаваться несколько раз. У файлов значения особые, поэтому в таком случае нужен отдельный способ кодирования.
07 / Контроль данных

Что проверяет браузер

Некоторые ограничения достаточно объявить прямо в HTML. Попробуйте отправить неверные значения. Браузер не позволит стандартно отправить форму и покажет сообщение. После исправления ошибки появится демонстрационный результат.

Проверка «живьём»

Форма ещё не проверена.

Что означают ограничения

1
required

Поле нельзя оставить пустым при стандартной проверке.

2
minlength / maxlength

Задают границы длины текстового значения.

3
min / max / step

Ограничивают подходящие числовые и временные поля.

4
type="email"

Включает базовую проверку синтаксиса адреса.

Не путайте проверку и сохранение. Успешное прохождение встроенной проверки означает лишь, что браузер не нашёл предусмотренных ею ошибок. Сервер должен повторно проверять значения.

09 / Качество

Подписи, удобство и распространённые ошибки

Форма должна быть понятной без догадок. Для этого важны постоянные подписи, логичная группировка, предсказуемые кнопки и сообщения об ошибках. Семантический HTML помогает пользователям клавиатуры и вспомогательным технологиям.

Удачный вариант

HTML
<label for="taskName">Название задачи</label>
<input id="taskName" name="title" required>
<fieldset>
  <legend>Видимость</legend>
  <label><input type="radio" name="access" value="private"> Личная</label>
  <label><input type="radio" name="access" value="team"> Командная</label>
</fieldset>

Подписи доступны, связь for → id явная, связанные варианты названы через legend.

Типичные ошибки

Пустая подпись: <label for="x"></label> не сообщает, что вводить.

Одинаковый id: два поля с одним id ломают однозначность связи.

Нет name: поле можно заполнить, но оно не будет включено в стандартные данные.

Кнопка без type: внутри формы обычная кнопка может неожиданно отправить форму.

Только placeholder: подсказка исчезает после ввода и не заменяет label.

Смысловое правило: сначала подбираем элемент по назначению, затем атрибутами уточняем его поведение, и лишь потом меняем оформление через CSS. Внешне похожие элементы могут выполнять совершенно разные задачи.

11 / Практический маршрут

Как проектировать форму для своего приложения

В работе над Organizer не нужно механически добавлять все существующие поля. Сначала определяется, какие сведения понадобятся для задачи, проекта или участника команды. Под каждое сведение выбирается подходящий HTML-элемент.

1
Опишите действие.

Например: «Пользователь создаёт задачу и выбирает приоритет, срок и исполнителя».

2
Составьте перечень данных.

Название, описание, статус, приоритет, срок, проект, исполнитель. Отметьте обязательные сведения.

3
Выберите элементы.

Название — input type="text", описание — textarea, приоритет — select, срок — input type="date".

4
Назначьте id, name и подписи.

У каждого поля понятная подпись. Имена name согласованы с будущей моделью данных.

5
Добавьте проверки и действия.

Потребуйте название через required, задайте нужные ограничения, предусмотрите кнопку type="submit".

6
Проверьте отправку.

Какие пары возникли? Что происходит с пустыми, отключёнными и неотмеченными полями? Какие проверки надо повторить на сервере?

Следующий шаг в курсе: после освоения HTML мы оформим форму средствами CSS, затем подключим обработчики JavaScript, а позднее — сохранение на сервере. Этот лонгрид можно использовать как справочник на каждом из этапов.
