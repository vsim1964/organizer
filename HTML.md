# HTML — учебные заметки

## Семантическая разметка

HTML описывает структуру и содержимое веб-страницы.

## Основные элементы

- header — шапка страницы или раздела.
- nav — область навигации.
- main — основное содержимое страницы.
- section — тематический раздел.
- article — самостоятельный блок содержимого.
- footer — нижняя часть страницы или раздела.
