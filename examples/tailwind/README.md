# Organizer — учебная версия на Tailwind CSS 4

Третий вариант оформления, размещённый отдельно от `index.html` и `style.css` в корне репозитория. Для сопоставления используются те же десять экранов, три диалога, поля и демонстрационные данные. JavaScript-навигация, сохранение и серверная авторизация пока не реализованы.

## Быстрый просмотр

Откройте `examples/tailwind/index.html` в браузере при подключённом интернете. Подключён официальный **Play CDN** Tailwind CSS 4. Он собирает утилиты в браузере и **предназначен только для разработки и учебных примеров**, а не для рабочего сайта.

## Локальная сборка через Tailwind CLI

Нужны Node.js и npm. Откройте в терминале каталог `examples/tailwind` и выполните:

```bash
npm install
npm run build
```

Скрипт создаст файл `output.css` на основе `input.css` и классов `index.html`. Для режима разработки можно запустить `npm run dev`.

После сборки, чтобы использовать CSS без браузерного компилятора, измените только подключение в `index.html`: удалите тег `<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>` и блок `<style type="text/tailwindcss">…</style>`, затем подключите в `<head>`:

```html
<link rel="stylesheet" href="./output.css" />
```

**Важно:** `output.css` не включён в репозиторий, потому что он генерируется инструментом сборки. Без `npm run build` переключать страницу с Play CDN на `output.css` нельзя. Зависимости установятся в каталоге этого примера и не затронут основное приложение.

## Чем Tailwind отличается от двух остальных вариантов

* Собственный CSS (`/style.css`): именованные БЭМ-классы с правилами в отдельной таблице стилей.
* Bootstrap (`/examples/bootstrap/`): готовые компоненты, сетка и классы фреймворка.
* Tailwind: утилитарные классы непосредственно в HTML, значения палитры задаются через `@theme` в исходном CSS; готовый CSS создаёт CLI.

## Проверка

Проверьте открытие страницы при ширинах 320, 390, 768, 1024 и 1440 px. В отсутствие JS-кода приложения виден экран задач; остальные экраны скрыты атрибутом `hidden`. Открытие диалогов и переключение разделов станут доступны после реализации JS.
