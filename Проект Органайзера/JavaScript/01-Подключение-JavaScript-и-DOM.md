# JavaScript в Organizer. Урок 1. Подключение скрипта и знакомство с DOM

**Этап:** I. Интерфейс и навигация  
**Шаг:** 1 из 17  
**Технология:** Vanilla JavaScript (без фреймворков)  
**Архитектурный ориентир:** функции + MVC  
**Исходный план:** [План поэтапной разработки JavaScript](../06-План-поэтапной-разработки-JavaScript.html)

## 1. Задача урока

Мы начинаем превращать статическую HTML-страницу Organizer в интерактивное приложение. Пока не создаём навигацию и не обрабатываем нажатия кнопок. Нужно проверить, что браузер выполняет подключённый JavaScript, научиться находить уже существующие элементы HTML и изменять текст на странице.

Результат первого шага — работающий файл `script.js`, который находит область служебного сообщения, считает элементы с атрибутом `data-screen-target` и выводит информацию о запуске. На этом шаге данные задач и проектов, формы и серверная часть не меняются.

## 2. Какие файлы задействованы

- **`index.html`** — HTML-структура страницы. В ней уже присутствуют элемент `<p id="appStatus">` и кнопки с `data-screen-target`.
- **`script.js`** — код первого урока. Здесь находятся только необходимые краткие комментарии; подробный разбор помещён в этот документ.
- **`style.css`** — оформление приложения; в первом уроке не изменяется.

В конце `index.html` подключён внешний скрипт:

```html
<script src="script.js" defer></script>
```

Атрибут `src` указывает браузеру путь к файлу. `defer` откладывает выполнение скрипта до завершения разбора HTML. Поэтому к моменту выполнения кода нужные элементы уже доступны через DOM. Это подключение было сделано в первоначальной реализации первого шага и сохраняется.

## 3. Что такое DOM и зачем он нужен

**DOM (Document Object Model, объектная модель документа)** — представление HTML-документа в памяти браузера в виде связанных объектов. Например, заголовок, кнопка и абзац становятся объектами, свойства которых доступны из JavaScript.

Сам HTML задаёт элементы и их исходное содержание. JavaScript с помощью DOM может найти нужный элемент, прочитать его свойства, заменить текст, добавить новый элемент или изменить видимость. В нашем первом примере он будет только находить элементы и изменять текст.

Глобальный объект **`document`** предоставляет доступ к текущему HTML-документу. Его методы `querySelector()` и `querySelectorAll()` принимают **CSS-селекторы** — выражения для поиска элементов, знакомые нам по CSS.

## 4. Разбор кода: три основных действия

### Действие 1. Найти место для сообщения

```javascript
const statusElement = document.querySelector("#appStatus");
```

Метод **`document.querySelector()`** находит первый HTML-элемент, соответствующий переданному селектору. Символ `#` означает поиск по идентификатору `id`. В `index.html` для этого предусмотрен элемент:

```html
<p class="status-message" id="appStatus" role="status" aria-live="polite"></p>
```

Переменная `statusElement` получает **ссылку на реальный элемент страницы**, а не копию его HTML. Благодаря этой ссылке мы сможем изменить содержимое абзаца. Если элемент не найден, метод возвращает `null`.

**Зачем это Organizer:** сюда можно помещать уведомления о результате действий пользователя. В будущем такой текст сможет сообщать о созданной задаче или ошибке. В этом уроке он сообщает только о запуске скрипта.

### Действие 2. Найти все элементы навигации

```javascript
const navigationButtons = document.querySelectorAll("[data-screen-target]");
```

Метод **`document.querySelectorAll()`** находит все элементы, соответствующие селектору. Квадратные скобки в CSS-селекторе обозначают поиск по HTML-атрибуту. В отличие от `querySelector()`, здесь результатом будет **`NodeList`** — коллекция найденных элементов (даже если она пуста).

Например:

```html
<button data-screen-target="tasksScreen">Задачи</button>
<button data-screen-target="projectsScreen">Проекты</button>
```

Значения `tasksScreen` и `projectsScreen` — идентификаторы экранов, которые эти кнопки должны открывать на следующем уроке. Сейчас JavaScript не нажимает кнопки и не переключает экраны; он только находит их.

Свойство **`navigationButtons.length`** сообщает количество найденных элементов. На момент выполнения этого шага в разметке Organizer их **13**.

**Зачем это Organizer:** вместо отдельных поисков каждой кнопки мы получаем всю группу элементов, предназначенных для навигации, и впоследствии сможем назначить им обработчики событий.

### Действие 3. Изменить текст в найденном элементе

```javascript
if (statusElement !== null) {
  statusElement.textContent =
    "JavaScript подключён. Найдено элементов навигации: " +
    navigationButtons.length + ".";
}
```

Свойство **`textContent`** задаёт текст внутри найденного HTML-элемента. Здесь оператор `+` соединяет строки с числом, полученным из `length`. Браузер показывает сообщение на самой странице без перезагрузки.

Конструкция **`if`** выполняет заключённый в фигурные скобки код только при выполнении условия. Выражение **`!== null`** проверяет, что искомый элемент существует. Это важно: если элемента нет, обращение к его `textContent` вызвало бы ошибку.

Для текста мы используем `textContent`, а не `innerHTML`: нам не требуется вставлять HTML-разметку. Значение `textContent` воспринимается как обычный текст.

**Зачем это Organizer:** приложение сможет менять сообщения, счётчики и другие текстовые элементы интерфейса в ответ на изменение своего состояния.

## 5. Дополнительные строки

В начале файла находится:

```javascript
"use strict";
```

Это директива строгого режима JavaScript. Он помогает раньше обнаруживать некоторые ошибки, которые язык в нестрогом режиме допускает.

В конце файла:

```javascript
console.log("Organizer: урок 1 — DOM доступен.");
```

Метод **`console.log()`** выводит диагностическую запись в консоль разработчика, а не на HTML-страницу. Он удобен при обучении и отладке. В данном случае запись подтверждает, что выполнение дошло до конца скрипта.

Ключевое слово **`const`** объявляет переменную, которой после присваивания нельзя назначить другое значение. Это не означает, что объект HTML, на который она ссылается, становится неизменяемым: его `textContent` мы свободно меняем.

## 6. Полный код первого урока

```javascript
"use strict";

// Урок 1. Проверка подключения JavaScript и доступа к DOM.
const statusElement = document.querySelector("#appStatus");
const navigationButtons = document.querySelectorAll("[data-screen-target]");

if (statusElement !== null) {
  statusElement.textContent =
    "JavaScript подключён. Найдено элементов навигации: " +
    navigationButtons.length + ".";
}

console.log("Organizer: урок 1 — DOM доступен.");
```

В этом файле нет функций переключения экранов, обработчиков событий, запросов к серверу или операций с задачами. Их добавим в соответствующих следующих уроках.

## 7. Как проверить результат

1. Откройте Organizer в браузере из актуальных файлов проекта.
2. Найдите сверху служебное сообщение: **«JavaScript подключён. Найдено элементов навигации: 13.»**
3. Нажмите **F12** и откройте вкладку **Console** («Консоль»).
4. Проверьте запись **«Organizer: урок 1 — DOM доступен.»**
5. Убедитесь, что экран задач по-прежнему отображается, а навигация не работает: её реализация запланирована на следующий шаг.

Если сообщение отсутствует, проверьте наличие `script.js` рядом с `index.html`, строку подключения, ошибки в консоли и существование элемента `#appStatus`.

## 8. Что мы получили и что изучим дальше

Теперь JavaScript умеет обращаться к существующему HTML-документу: искать один элемент, находить группу элементов и менять текст на странице. Это основа дальнейшей интерактивности.

**Следующий шаг — урок 2: переключение экранов.** Познакомимся с событиями, `addEventListener()`, атрибутами `data-*` и свойством `hidden`. Каждая навигационная кнопка должна будет открывать соответствующий экран.
